# WW3: High Command (OpenFront for Roblox) — project notes

Roblox/Luau port of OpenFront (territory-conquest RTS). Title: "WW3: High Command" (`src/shared/GameInfo.luau`).
Place file: `build/OpenFront.rbxlx` (generated by `node tools/build.mjs` from `src/` + `tests/`). Edit `src/`, not the build output.

## Layout
- `src/server/GameServer.server.luau` — lobby, tick loop, all Intent handling, Query. Re-clones itself per match.
- `src/server/Core/**` — port of the upstream simulation. Fork changes on purpose: fair start (25000 troops), longer spawn phase,
  directed attacks (`focusTile`), 6-tile structure spacing for humans. Golden tests (`SimSpec`) therefore mismatch from tick ~100.
- `src/server/{Profiles,ShopService,Progress,Matchmaking}.luau` — DataStore profiles (session lock, read-only on load failure),
  shop/receipts + daily reward, badges + wins leaderboard, MemoryStore matchmaking.
- `src/shared/Net.luau` — remotes and buffer packing. `src/client/**` — renderer + HUD; `HighCommand.luau` is the main menu shell
  (hides the old `LobbyScreen`). `Main.client.luau` CLIENT_MODULES must match module files or the build fails.
- `*.orig` files in src/ are stale backups, NOT built.

## Working rules
- No git binary on PATH; Node is needed for build and tools.
- Studio MCP (Roblox_Studio) is connected via `.mcp.json`. Sync: edit `src/`, mirror the same edits into the open place with
  `multi_edit`/`execute_luau` (HttpService to localhost is blocked), test with a playtest, then `node tools/build.mjs`.
- Monetization policy: cosmetics / lobby convenience only. Ids in `src/shared/Data/Shop.luau` are 0 until
  `node tools/setup-shop.mjs --universe <id> --key <API key>` runs after publishing. Rebirth stays unsold (pay-to-win).

## Server kinds (Matchmaking.serverKind)
- public: root servers and reserved public lobbies; 60 s countdown then auto-start. Menu shows the countdown on MAIN.
- solo: reserved for one player; the menu settings travel in TeleportData and the match auto-starts. All options free.
- custom: private match / duel (join code). Host starts it from ONLINE ("START MATCH") or DUEL. Studio runs as custom.
- Test a mode in Studio with the GameServer attribute `LobbyMode` (remove it afterwards).
